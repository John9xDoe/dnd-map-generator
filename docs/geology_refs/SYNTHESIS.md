# Синтез принципов (геоморфология / гидрология / ландшафт)

Опора: fluvial geomorphology (drainage basins + hillslopes; River Dynamics —
bridge/preview PDF в `river_dynamics_preview.pdf` / extract), Barnes Priority-Flood,
stream-power law (E = K A^m S^n), thermal/talus erosion, Beven–Kirkby TWI.

Локальные артефакты изучения: `river_dynamics_extract.txt`, `river_dynamics_ch1_2_snip.txt`.

## Водосбор и сеть русел
- Ландшафт делится на водосборы; сток с холмов → в русловую сеть → к устью.
- Каналы зарождаются, когда поверхностный/подповерхностный сток превышает порог
  устойчивости склона (channel initiation), а не «рисуются» случайно.
- Сеть растёт иерархически (притоки → ствол); масштаб самоподобен (Hack / Horton).

## Склоны
- Hillslope-процессы (creep, splash, talus) сглаживают уклоны выше угла естественного
  откоса — отсюда thermal erosion с порогом tan(φ).
- Обрывы — протяжённые эскарпы, не россыпь пикселей: нужен связный фронт уступа.

## Реки и озёра
- Реки следуют линиям максимального накопления стока после заполнения котловин.
- Озёра — достаточно глубокие замкнутые депрессии (до перелива), не любой шум ямы.
- Поймы/берега влажнее (TWI) → лес тяготеет к ним, но не растёт в воде.

## Лес
- Ограничения: нет воды, нет крутых обрывов, умеренная высота, конкуренция крон.
- Буфер вокруг воды обязателен: знаки деревьев имеют размер >1 клетки.
